WORKING DEFINITION

ML

Machine learning

Methods that fit a model or policy from data or experience to perform a specified task.

Proposed; pending team confirmation.

Scope

The learning process and resulting model or policy, rather than the whole surrounding software system.

Includes

  • Supervised, unsupervised, and reinforcement learning; learning used for prediction or generation.

Excludes

  • A synonym for all AI or an assurance that a model generalizes successfully.
  • A requirement that every change to software be learned from data.

Ambiguities and boundaries

  • Training and using a trained model are different activities, even when both are described informally as ML.
  • Generative describes an output capability; supervised and unsupervised describe learning arrangements. These labels are not a single exclusive taxonomy.

Operational criteria

Identify what is learned, the data or experience used, the task or objective, and the evaluation setting. Distinguish training from later use.

This project's chosen working meaning

Project choice: use a broad learning-method sense, informed by Google's technical introduction, while keeping learning arrangement separate from output capability. Pending team confirmation.
