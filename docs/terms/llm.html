LLM

Large language model

A large language model is a deep learning language model trained on very large textual datasets. It is a kind of Model; its complete application or agent runtime is a separate system. [8] [14] Editorial interpretation

Definition comparison

EU-U.S. terminology

Institutional; language models

The second edition emphasizes deep learning and extremely large text datasets, and includes models that generate text or form representations useful for downstream tasks. [8]

GPT-3 study

Peer-reviewed; a specific experimental scale

Brown and colleagues study an autoregressive model with 175 billion parameters alongside smaller models. Its training corpus mixes web sources, books and Wikipedia; that recipe is an example, not a definition. [9]

Scope

This page concerns learned language models, including text generation and representation uses. The word “large” needs a stated scale and comparison context. [8] [9] Editorial interpretation

Includes

  • A trained text-generation checkpoint is a model artifact; adding retrieval, tools and execution control creates a larger application around it. [13] [14] Editorial interpretation
  • Representation-producing language models are within the cited institutional usage; generation is not its only permitted behavior. [8]

Excludes and counterexamples

  • A corpus alone is training material, not a trained model. A tool-connected assistant is not identical to the language model inside it. [14] Editorial interpretation
  • No universal parameter cutoff is established by the sources used here. Report parameters, training tokens and the relevant comparison rather than inventing a threshold. [9] [14] Editorial interpretation

Different usages and open boundaries

  • The institutional definition foregrounds textual training. For a multimodal product, specify its language-model component and additional modalities instead of assuming the same definition covers the whole system. [8] [14] Editorial interpretation
  • Training a model and conditioning an inference call are different operations: the GPT-3 few-shot experiments add examples in context without gradient updates. [9]

Operational criteria

Repository test: identify the learned model artifact, language task and objective, available training-material evidence, and reported scale. Record unknown proprietary details as unknown. Separately identify any tokenizer, serving system, tools and controller. [14] Editorial interpretation

Concept relationships

Only is-a means a strict subtype. Uses and supports/orchestrates describe composition and control.

  • Model
    • LLM is-a

      Within learned AI-model usage: an LLM is a specialized language model, hence a Model. [8] Editorial interpretation

Workflow uses LLM

An LLM workflow uses an LLM for one or more tasks; many workflows use no language model. [13] Editorial interpretation

Harness uses LLM

In an LLM-based agent runtime; evaluation harnesses and other harness usages have different scopes. [4] [6] Editorial interpretation

Agent uses LLM

For LLM-based agents only; general agents need not use a language model. [11] [13] Editorial interpretation

Repository working definition

Repository · Proposed / not certified

Use LLM for a learned language-model component at a documented large scale. Avoid reducing the term to corpus size alone or using it as the name for a tool-using system. No minimum parameter count is ratified by the repository. [14]

No consensus decision recorded.
