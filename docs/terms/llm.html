WORKING DEFINITION

LLM

Large language model

A language model trained at substantial scale to model patterns in token sequences and support language tasks.

Proposed; pending team confirmation.

Scope

The language-model component, rather than a complete chatbot or application.

Includes

  • Language models used for token prediction, generation, or language representations, with the specific use stated.

Excludes

  • A synonym for the interface, retrieval system, tools, or orchestration around a model.
  • A universal numerical boundary for large.

Ambiguities and boundaries

  • Large is relative to the model family and period; parameter count alone does not settle the label.
  • Some current models accept multiple modalities. Specify the model's input and output modalities rather than relying on LLM as the whole description.

Operational criteria

Record a public model identifier and version, the language-modeling function, and known scale and modalities. Leave unavailable details unknown; do not invent a parameter cutoff.

This project's chosen working meaning

Project choice: use LLM for the language-model component and qualify scale and modalities when material. Google's technical explanation informs the language-model sense; team confirmation is pending.
